# JavaScript Yol Haritası

Her konu kendi klasöründe: her klasörde `ders.md` (konu anlatımı) ve `pratik.js`
(kod yazdığın yer) bulunur. Bir konu bitince kutucuğu `[x]` yaparız.

## Temeller

- [x] 01 — Konsola Yazdırma (`console.log`)
- [ ] **02 — Değişkenler (bilgiyi saklamak)** — şu an buradayız
- [ ] 03 — Veri Tipleri (metin, sayı, doğru/yanlış)
- [ ] 04 — Metinler / Stringler (birleştirme, şablonlar)
- [ ] 05 — Sayılar ve Matematik
- [ ] 06 — Karşılaştırma ve Boolean
- [ ] 07 — Koşullar (`if` / `else`)
- [ ] 08 — Diziler / Arrays
- [ ] 09 — Döngüler / Loops
- [ ] 10 — Fonksiyonlar
- [ ] 11 — Objeler / Objects
- [ ] 12 — Dizi Metotları (`map`, `filter`, `find`)

Sonraki konular (async, modüller, DOM) bunların üstüne gelecek.

## Çalışma düzeni

1. `ders.md` dosyasını oku.
2. `pratik.js` içinde kod yaz.
3. Çalıştır: `node lessons/<klasör>/pratik.js`
4. Çoğu derste çalıştırmadan önce sonucu tahmin etmen istenir.
